# 일본어 단어장 — PWA

수업에서 받은 종이·PDF를 사진 한 장으로 단어장에 담고, 날짜별로 묶어 카드와 퀴즈로 외웁니다.

**배포 주소: https://ycimmich-cpu.github.io/japanese-vocab/**

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 |
| `kanji.json` | 한자 획순 자료 2,325자 (상용한자 + 가나) — **KanjiVG** |
| `manifest.webmanifest` | 앱 이름·아이콘·화면 설정 (홈화면 설치 정보) |
| `sw.js` | 오프라인 캐시 담당 (service worker) |
| `icon-*.png` `apple-touch-icon.png` `favicon-32.png` | 아이콘 |

> **중요**: 파일은 반드시 같은 폴더에 **평평하게** 두어야 합니다. 하위 폴더로 옮기면 서로를 못 찾습니다.

## 기능
- **사진·PDF·워드에서 단어와 지문을 자동 등록** (본인 Claude API 키 사용)
- 날짜(수업 회차)별로 묶어 카드 학습 · 4지선다 퀴즈 (단어→뜻 / 뜻→단어 / 듣고 맞추기)
- 학습 상태 **よし**(알고 있어요) / **まだ**(더 학습할게요) 로 나누고 범위를 골라 학습
- 예문 낭독 · 한자 후리가나 루비 · **한자 획순 보기**
- 문장 읽기(음독) — 지문을 등록하고 소리 내어 읽은 횟수를 기록

## 데이터는 어디에 있나요
**서버가 없습니다.** 단어·지문·기록·설정은 전부 **이 기기의 브라우저 안**에 저장됩니다.
API 키도 기기에만 저장되고 **백업 파일에도 들어가지 않습니다.**
사진은 인식할 때 **Anthropic API 로 한 번 전송**되고, 앱은 그 원본을 서버에 남기지 않습니다.

## 왜 웹에 올려야 하나요?
홈화면 설치와 오프라인 기능(service worker)은 브라우저 보안 정책상 **HTTPS 주소에서만** 동작합니다.
바탕화면의 HTML 파일을 더블클릭하는 `file://` 방식으로는 설치가 불가능합니다.
