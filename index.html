사진 인식 (AI)
사진·문서에서 단어와 지문을 자동으로 만들어 등록합니다. Claude API 키가 필요하고 쓴 만큼만 차감됩니다.
키는 이 기기 안에만 저장되고 백업 파일에도 들어가지 않습니다. 키가 없으면 사진은 보관만 되고, 나중에 키를 넣었을 때 한꺼번에 인식할 수 있습니다.
API 키는 어디서 받나요?
1. console.anthropic.com 에 접속해 계정을 만듭니다 (구글 로그인 가능).
2. Billing 에서 결제 수단을 등록하고 5달러만 충전합니다. 월 요금제가 아니라 선불이라, 넣어 둔 만큼만 쓰고 자동으로 더 나가지 않습니다.
3. API keys → Create Key 를 누르고 나온 sk-ant- 로 시작하는 문자열을 복사해 아래 칸에 붙여넣습니다.
⚠ 키는 만들 때 딱 한 번만 보입니다. 창을 닫기 전에 복사해 두세요.
사진 한 장에 약 16원입니다 (Haiku 4.5 · 실제 사진 12장으로 잰 값). Sonnet 은 같은 품질에 약 46원이라, 특별한 이유가 없으면 추천 표시가 붙은 쪽을 쓰시면 됩니다.
데이터
데이터는 이 기기의 브라우저 안에 저장되며, PC와 휴대폰은 따로 관리됩니다. 앱 파일을 새 버전으로 바꾸기 전에 백업을 먼저 내보내 주세요. 휴대폰으로 옮길 때도 백업 파일을 내보낸 뒤 휴대폰에서 불러오면 됩니다.
